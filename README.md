ARCHIVOS
- index.html: página de ventas responsive.
- portada-original.png: portada renderizada desde el PDF enviado.
- muestra-*.png: páginas interiores renderizadas directamente desde el PDF para la vista previa.

PRECIO Y ENLACE DE PAGO
Al final de index.html, edita LANDING_CONFIG:
- priceText: actualmente "$9.900 COP".
- checkoutUrl: pega el enlace de pago de Hotmart, Gumroad, Systeme.io u otra plataforma.

PUBLICACIÓN
Sube index.html y todos los PNG de esta carpeta al mismo directorio en tu alojamiento web. Carga el PDF como producto en la plataforma de pago y configura ahí su entrega después de la compra.

CONTENIDO
El precio está expresado como COP. El PDF enviado contiene una portada y nueve páginas de planificación. No contiene recetas ni bonos descargables por separado; la página presenta páginas reales del archivo y explica su contenido sin atribuirle materiales adicionales.
